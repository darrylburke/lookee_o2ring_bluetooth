Ask questions about your data

Type a question in plain English – “Why was last night worse than the one before?”, “When were my drops clustered?” – and Claude, Anthropic's AI model, looks up the numbers in your own database and answers. It is optional and switched off until you add your own Anthropic API key.

This is a saved report file. Asking needs the report server – start it with cd server && npm start and open the report from http://127.0.0.1:3000.

  1. Create an API key at console.anthropic.com (Settings → API keys). Usage is billed to your Anthropic account.
  2. Add one line to the .env file in the project folder:
    ANTHROPIC_API_KEY=sk-ant-…your key…
  3. Restart the report server. The panel wakes up.
What leaves your computer when you ask
  • Your question, and only the figures the model looks up to answer it: nightly metrics, the list of oxygen drops, signals averaged over minutes, your tags and your free-text notes (set O2RING_LLM_SEND_NOTES=0 to keep notes out).
  • Never the ring's serial number, and nothing at all until you press Ask. Hidden recordings are not readable by the fixed tools – the optional SQL tool can see their rows, and is told to leave them out.
  • It goes to Anthropic's API under your key and their terms. Questions and answers are kept in your own MySQL database so a conversation can continue; delete them any time.
  • The optional SQL tool is on: the model may also run its own read-only SELECT queries, through a database user that can only read.
  • Each night also gets a short “morning summary”, written once from that night's numbers and stored.
  • Cost with the default model is roughly 2–10 US cents per question, depending on how much it looks up, and about 2 cents per summary. O2RING_LLM_DAILY_LIMIT (default 100) caps questions per day; O2RING_LLM_MODEL picks the model.

Answers are generated by an AI model from a consumer device's data. They can be wrong, and they are not medical advice or a diagnosis.
